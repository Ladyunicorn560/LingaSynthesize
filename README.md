# 🌍✦ LingaSynthesize: Global Intelligence Terminal

**LingaSynthesize** is a state-of-the-art Autonomous Multi-Agent Research System designed to bridge the global language gap. Built on **LangGraph** and **Google Gemini 1.5 Flash**, it orchestrates specialized AI agents to retrieve, translate, and synthesize intelligence from diverse language sources (Japanese, German, English) into high-fidelity strategic reports.

---

### 🎯 Mission Objective
Traditional RAG systems are limited by the "English-only" bubble. LingaSynthesize breaks this barrier by neutralizing language barriers in real-time, accessing regional research and frameworks that are often invisible to standard English queries.

### 🧠 Core Architecture (Multi-Agent Engine)
The system operates as a **Reasoning Engine** with three primary nodes:
- **Strategic Supervisor**: Defined search strategies and routes objectives.
- **Global Researcher**: Translates queries and retrieves data from Japanese (JP), German (DE), and English (EN) nodes via **Tavily**.
- **Intelligence Synthesizer**: Normalizes multi-lingual data and generates a cohesive English report with full source attribution.

---

### 🚀 Key Features
- **Cross-Lingual Intelligence**: Automated real-time translation and research in 3+ languages.
- **Mission Control UI**: A premium, luxury-grade dashboard with Midnight Navy & Champagne Gold aesthetics.
- **Evidence Wall**: Full traceability with an evidence log showing the specific global sources used.
- **MLOps Verification**: Built-in evaluation protocol (Faithfulness, Relevance) to ensure intelligence grounding.
- **Live Reasoning Logs**: Real-time visibility into agent decisions and strategy logic.

---

### 🛠️ Tech Stack
- **Framework**: LangGraph / LangChain
- **LLM**: Google Gemini 1.5 Flash
- **Search Engine**: Tavily API
- **Backend**: FastAPI (Python)
- **Frontend**: Vanilla JS / CSS (High-Performance Modern UI)
- **Evaluation**: Ragas / Custom MLOps Protocol

### ⚙️ Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ladyunicorn560/LingaSynthesize.git
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure Environment**:
   Create a `.env` file with your keys:
   ```text
   GOOGLE_API_KEY=your_key
   TAVILY_API_KEY=your_key
   ```

4. **Launch the Engine**:
   ```bash
   python app.py
   ```
   Access the dashboard at `http://localhost:8000`.
